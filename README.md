# 智营 RPA 数据驾驶舱 PoC

面向电商运营的本地演示项目：将淘宝/天猫、京东、抖音的经营数据按统一口径汇总，呈现经营日报、SKU 风险、异常流转和 RPA 任务状态。它是一个从 0 到 1 的能力验证 PoC，不是已接入任何企业生产系统的声明。

## 本地启动

要求：Node.js 20+。

```bash
npm install
npm run dev
```

终端会显示本地访问地址。生产构建可运行：

```bash
npm run build
```

## 测试

```bash
npm run test:run
npm run build
```

## 3–5 分钟演示路线

1. 在经营总览切换“昨日 / 近 7 天”和渠道，说明所有 KPI、趋势和渠道贡献均随全局筛选同步变化。
2. 进入每日经营日报，按“发生了什么 → 为什么 → 今天建议做什么”讲解运营结论。
3. 进入异常中心，打开一个库存、转化或合规异常，并演示待处理到处理中/已解决的留痕闭环；不同角色仅展示各自允许的操作。
4. 进入商品分析和自动化任务，说明 SKU 风险定位、失败任务保留上一次成功快照，以及“成功任务数 × 单次标准人工耗时 ÷ 60”的模拟节省工时口径。
5. 在数据接入与行业规则页导出当前筛选的 Power BI CSV；说明三渠道适配器、医药规则包和未来接入边界。

## 模拟数据与合规披露

- 所有数据均为项目内置的模拟、脱敏数据，按每日 08:30 的模拟任务刷新展示。
- PoC 不登录真实平台、不采集真实用户信息、不执行自动回复、私信、加粉、调价、退款或 ERP/WMS 写入。
- Power BI 交付物仅为当前筛选条件下的 CSV、字段字典和连接说明；不会承诺企业报表嵌入、网关、刷新权限或 `.pbit` 模板。
- CSV 坚持白名单字段：`date`、`channel`、`sku`、`visits`、`paidOrders`、`paidAmount`、`refundedAmount`、`stock`、`averageDailySales`，不包含可识别个人身份的信息。

## 真实集成前提

生产接入前须由企业确认并授权：各平台开放接口/后台导出权限，ERP/WMS 数据接口，跨平台 SKU 与指标口径，Power BI 数据模型、网关及刷新权限，以及医药合规、账号权限和个人信息处理边界。系统设计将真实接入隔离在适配器层，后续可替换数据来源而无需重写经营指标、异常规则和网页看板。
