# 智营 RPA 数据驾驶舱 PoC

面向电商运营的本地可运行作品集：统一展示淘宝/天猫、京东、抖音的经营数据、异常流转、自动化任务，以及“公域需求雷达”的合规线索运营闭环。

## 本地启动

要求：Node.js 20+

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 公域需求雷达演示路径

1. 在左侧进入“公域需求雷达”，说明数据来源、需求漏斗、高优先级线索和三渠道降级状态。
2. 点击“查看高优先级线索”，进入“合规审核工作台”。
3. 展示脱敏评论、命中词、AI 科普草稿、强拦截边界和模型匹配度仅用于运营排序。
4. 点击“人工确认”后状态变为“待外部执行”；“复制草稿”不改变状态。
5. 点击“外部动作打卡”，状态才变为“外部执行已打卡”，并产生 `external_action_logged` 留痕。
6. 在“导入与规则中心”导入脱敏 CSV；含手机号、邮箱等可识别信息的行会被本地拦截并显示行号与原因。

## 合规与数据边界

- 所有内置数据均为模拟、脱敏数据。
- CSV 文件只在浏览器本地读取与校验，不上传服务器。
- 不实现未经授权采集、绕过平台限制、养号、多账号批量操控、自动评论、自动私信或自动发布。
- 员工自有账号仅可用于客户本地、获授权的人工辅助流程；账号密码、Cookie、登录态不进入系统。
- 健康相关内容仅生成科普草稿，必须人工审核；不提供诊疗建议、处方药推广或功效承诺。
