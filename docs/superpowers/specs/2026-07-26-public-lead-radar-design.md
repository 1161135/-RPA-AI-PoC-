# 公域需求雷达与合规线索运营工作台：设计说明

## 目标

为健康电商运营提供一个可演示、可本地运行的线索运营工作台：将已获准使用的公开样本或脱敏 CSV 导入系统，完成需求识别、意图分级、AI 草稿、合规审核、人工确认与结果回看。

本模块不是自动获客、自动群发或平台绕过工具。它的核心价值是把分散的公开互动样本转化为可追溯、可审核的运营队列，并为企业后续接入官方 API 或客户本地 RPA 辅助流程提供边界清晰的接口。

## 适用范围和明确边界

### 首期 PoC 包含

- 抖音、淘宝/天猫、京东三渠道的模拟脱敏数据与适配器状态。
- 本地 CSV 导入，字段校验、敏感字段拦截、行号级错误提示和导入摘要。
- 关键词、意图、线索优先级、去重、漏斗流失归因。
- AI 生成的健康科普草稿、规则命中、改写建议和知识包来源标注。
- 人工审核、负责人分配、状态流转、通知预览、操作留痕和导出。
- 规则版本记录和回滚演示。
- 实时 / 快照 / 模拟样本三档数据降级。

### 首期明确不包含

- 绕过平台限制、规避检测、养号、批量账号控制、验证码处理、未经授权的数据采集。
- 自动评论、自动私信、自动发布、自动调价或自动写入真实订单。
- 跨平台身份画像、真实个人信息导入、手机号等可识别字段掩码后留存。
- 诊疗建议、处方药推广、功效保证或商品购买引流。

### 数据接入类型

| 类型 | 含义 | 系统允许的动作 |
| --- | --- | --- |
| 官方 API 已授权 | 取得平台应用和接口权限 | 在获准字段及范围内读取，显示数据新鲜度 |
| 员工自有账号授权 | 员工在客户本机登录后，授权 RPA 辅助其被批准的流程 | 打开待办、生成/复制审核草稿、提醒人工操作、记录本地操作结果；不作为数据采集许可 |
| 已获准导入样本 | 企业已确认来源、用途和脱敏状态的 CSV | 本地导入、校验、分析和脱敏导出 |
| 快照降级 | 最近一次成功的已获准数据快照 | 只读展示，标注快照时间 |
| 内置模拟样本 | PoC 演示数据 | 演示全流程，永久标注“模拟数据” |

账号密码、Cookie、登录态均不进入本系统。员工账号授权可撤销，需记录授权人、授权范围、有效期限和企业内部审批编号。

## 用户、角色与权限

| 角色 | 权限 |
| --- | --- |
| 管理层 | 查看指挥台、漏斗、风险、汇总和脱敏导出；无审核/发送动作 |
| 运营主管 | 查看全部线索，分配负责人，调整优先级，审批规则版本，重开关闭线索 |
| 运营专员 | 仅处理自己负责的线索；提交审核说明、采纳改写、人工确认和跟进结果 |

## 核心页面

### 1. 公域需求雷达（首页）

顶部显示筛选条件、数据来源和数据新鲜度。主体依次展示：

1. 今日命中、待审核、高意向、人工确认、强拦截、平均承接时效。
2. 需求雷达：渠道、需求类别、关键词趋势与高优先级线索。
3. 运营漏斗：导入记录 → 有效样本 → 已识别 → 高意向 → 待审核 → 人工确认 → 已跟进；每层附带流失原因。
4. 渠道适配器状态：授权类型、运行状态、最后成功时间、降级等级。
5. 待处理异常：导入失败、规则版本待审批、合规强拦截、逾期线索。

点击高优先级线索进入审核工作台。

### 2. 合规审核工作台（详情）

左侧为线索队列，支持渠道、风险等级、状态、负责人、关键词、时间筛选。中间显示脱敏评论上下文、命中的关键词、意图理由、模型匹配度和重复事件。右侧显示 AI 草稿、知识包名称/版本/审核日期、规则命中和改写建议。

状态机：`待审核 → 审核中 → 待人工确认 → 已人工确认 → 已跟进`，另有 `已忽略`、`强拦截`。每次流转必须记录操作者、时间、处理方式、说明和规则版本。

“一键应用改写”只更新草稿，不改变发送状态。人工确认后系统仅生成“已确认发送”模拟记录与企业微信通知预览；真实平台动作始终由获授权人员在平台内完成。

### 3. 导入与规则中心

#### CSV 导入

必填字段：渠道、内容标识、脱敏评论、发生时间。可选字段：脱敏用户标识、原始关键词、来源凭据编号。

校验：缺字段、非法渠道、无效日期、重复记录、疑似姓名/手机号/邮箱/地址、非脱敏账号标识、超长文本。系统返回错误行号、字段、原因和修正建议。PoC 在浏览器内解析，文件不上传服务器、不写入持久化存储。

#### 关键词与意图规则

四类词库：症状词、需求词、决策词、负向过滤词。预置眼部不适、皮肤修复等 20 组脱敏演示词。

分级规则：

- 高意向：症状词 + 决策词，或人工升级。
- 中意向：症状词 + 需求词。
- 低意向：仅相关话题，无明确诉求。
- 过滤：命中负向过滤词或无关话题。

去重仅在导入批次内按内容指纹与脱敏事件标识执行；首期不跨渠道关联身份。

#### 合规规则

- 强拦截：处方药、诊疗承诺、绝对化功效、规避审查等；不可确认发送。
- 弱提示：轻度营销化表达；生成改写草稿后进入人工审核。
- 预警：无明确违规但包含健康相关高风险词；在审核界面高亮。

所有健康科普草稿强制添加“本文仅为健康科普信息，不构成医疗建议；如有不适请咨询专业人士”的不可删除标识。该标识不替代广告、药师或法务审核。

规则按渠道配置，具备版本号、发布人、发布时间、变更说明、启用状态和回滚入口。

## 模型与知识包

`AiSuggestionService` 只接受脱敏上下文和经过批准的知识包。输出包含草稿、风险词、改写建议、模型匹配度和知识包元数据。

模型匹配度仅辅助运营排序；不代表医学结论、不触发自动发送、不用于对个人作自动化决定。系统将 AI 输出显著标为“生成草稿”。知识包记录名称、版本、适用范围、审核人和审核日期，不硬编码未经企业确认的指南出处。

## 适配器与容错

```text
PlatformAdapter (渠道/导入来源)
  -> LeadNormalizationService (字段校验、脱敏检查、去重)
  -> LeadScoringService (关键词、意图、优先级、流失原因)
  -> AiSuggestionService (受控知识包草稿、合规初检)
  -> ReviewWorkflowService (角色权限、状态机、留痕)
  -> NotificationService (企业微信通知预览/未来适配器)
  -> DashboardQueryService (指标、漏斗、趋势、异常)
```

适配器状态：

- 正常：在授权范围内有可用数据。
- 轻度降级：连接异常，使用 24 小时内最近一次成功快照。
- 完全降级：无可用授权数据，切换到内置模拟样本。

所有降级数据必须显示来源、更新时间和状态色，禁止将不可用或缺失的数据展示为零。

## 数据安全与生产化原则

PoC 的输入仅限脱敏样本，在浏览器内处理；刷新后不保留导入文件。生产化目标采用 HTTPS（优先 TLS 1.3）、服务端加密存储、最小权限、租户隔离、访问审计、保留期限和删除机制。原始健康、账号、联系方式等敏感信息不进入模型提示词或演示导出。

任何真实接入前均需完成平台规则核对、企业内部审批、个人信息处理合法性评估、药师/法务审核和数据处理协议确认。

## 验收标准

1. 可从模拟数据或合规 CSV 走通“导入 → 校验 → 识别 → 分级 → AI 草稿 → 审核 → 人工确认 → 通知预览 → 结果回看”。
2. 含敏感字段的 CSV 被拦截，并显示具体错误行号与原因。
3. 管理层、主管和运营专员看到不同操作权限。
4. 强拦截内容不能进入人工确认；弱提示只能修改草稿后送审。
5. 每次状态流转显示完整操作历史。
6. 渠道故障可切换快照或模拟样本，并明确标注数据性质。
7. 规则修改产生版本记录，可查看并回滚。
8. 新增领域逻辑拥有单元测试；关键导入、审核、权限和降级流程拥有浏览器测试。
