# 智营 RPA 数据驾驶舱：5 分钟演示脚本

## 开场（30 秒）

这不是一个把 RPA 当作“自动点按钮”的演示，而是一套电商运营中台 PoC：把获客、定价、履约和内容合规放到同一套规则、权限、审计和降级机制下。当前展示的均为模拟脱敏数据，真实平台动作始终由获授权人员在外部平台完成。

## 1. 经营总览（45 秒）

先展示全局时间、渠道和角色筛选。经营数据与自动化状态被分开展示：例如「渠道适配器就绪率」反映数据接入可用性，成功任务次数反映任务运行量，避免把两个不同分母混成一个指标。异常中心把管理者从“看报表”带到“找待办”。

## 2. 公域需求雷达（75 秒）

这里演示的是合规线索运营，而不是自动抓取或自动回复。CSV 在浏览器本地校验，含手机号、邮箱等直接可识别信息会被拦截。导入后，系统按症状、需求、决策与负向词给线索分级；运营人员查看 AI 科普草稿并人工确认。点击复制只准备话术，必须在获授权的外部客户端中人工发送；回到系统完成外部执行打卡，才形成可审计的闭环。

## 3. 竞品价格监控（60 秒）

价格工作台先处理竞品映射、异常价格过滤和渠道差异阈值，再给出跟随竞品、毛利保底或目标锚定三类建议。系统会在建议价穿透毛利安全线时高亮熔断风险。运营专员不能直接改价，主管批准后仍需在外部平台人工执行并登记实际价格或凭证。

## 4. 订单与售后（60 秒）

订单异常和售后工单不混为一谈：订单异常可合并多条命中规则，并按最高风险进入人工复核；售后工单按退款、补发、咨询分别设置 SLA 和打卡字段。以补发为例，只有填写物流单号和补发规格后，才能把外部动作记入审计记录。

## 5. AI 素材与合规（60 秒）

最后是内容生产与合规。草稿先经过通用医学广告规则和渠道规则的从严判定：强拦截无法绕过终审，弱提示可以采用低风险改写，预警标记会进入人工审核。每一条草稿关联知识库版本；复用模板也必须重新检测和审核。内容获批后仍以外部发布打卡作为闭环，而非自动发布。

## 收尾（30 秒）

这个 PoC 的价值不只是几个页面，而是把“能自动化的效率”和“必须人工承担的责任”分开：统一数据模型、规则版本、角色权限、降级容错与审计留痕可复用于不同渠道和行业。未来可在获得正式接口与业务授权后，把模拟适配器替换为真实数据连接器。
